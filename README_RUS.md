# Python: управление пакетами и виртуальная среда
# Yahoo Finance Parse

Проект по сбору и анализу финансовых данных с Yahoo Finance с использованием парсинга HTML, профилирования и модульного тестирования.

## О проекте

Этот проект был выполнен в рамках обучения в **Школе 21** (проект DSB4_Package_management). 

Основной целью была освоить:
- работу с виртуальными окружениями Python
- управление пакетами через "requirements.txt"
- парсинг веб-страниц с помощью BeautifulSoup
- профилирование и оптимизацию кода с cProfile
- написание модульных тестов с PyTest

Проект представляет собой ETL-инструмент, который:
1. принимает тикер компании (например, `MSFT`) и название финансового показателя (`Total Revenue`)
2. парсит страницу Yahoo Finance
3. возвращает кортеж с запрошенными данными
